FAQ

常见问题

快速了解 ToolDelta-Web 的关键信息。

ToolDelta-Web 是什么？
基于 Web 的 Minecraft 服务器管理面板，内嵌 ToolDelta 引擎。无需安装客户端，浏览器打开即用。MIT 开源，自部署、数据完全自持。
需要什么环境运行？
Python 3.10+。首次运行时面板会引导安装 ToolDelta 运行依赖，支持本地离线包（无外网可用）与在线安装两种方式。Windows / Linux / macOS 均可运行。
支持手机访问吗？
完全支持。深度适配 Android：滑动手势打开侧栏、软键盘弹起自动补偿、刘海安全区避让、动态视口高度。移动端体验与桌面端一致。
支持哪些主题？
深色、浅色、跟随系统三种主题。用 CSS 变量驱动，切换瞬时无闪烁。可在设置页选择，或用 ⇧+T 快捷键切换。
误删插件怎么办？
删除操作会先在前端软删除，并弹出 6 秒撤销窗口的 Toast。点击「撤销」即可恢复；窗口关闭后才真正提交到服务器。即便请求失败也会自动回滚，不会丢数据。
有键盘快捷键吗？
有。按 ⌘+K 打开命令面板（模糊搜索 + 最近访问），? 查看全部快捷键，/ 聚焦页面搜索框。
项目稳定吗？
每次构建运行 10 轮独立自检（共 2530+ 断言），覆盖启动/停止/重启/日志/收藏/连接/看门狗/调度/仪表盘等模块。GitHub Actions CI 在每次 push 时自动跑自检与构建归档。
